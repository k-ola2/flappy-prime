# Flappy PRIME

Robot warrior edition of Flappy Bird. Single-file HTML canvas game, no dependencies. Open index.html in a browser.

Controls: tap, click, or press Space / Up Arrow / Enter to flap. Tap or press again on the game over screen to retry.

Features:
- Day/night cycle: the sky shifts from day to dusk to night as your score rises.
- Power-ups: orbs spawn in pipe gaps sometimes. "S" (cyan) is a shield that blocks one hit and gives brief invulnerability. "T" (purple) slows time for about 5 seconds. HUD shows active power-ups.
- Hard mode after 15 points: narrower gaps and faster scrolling.
- Polish: flapping jets animate on each flap and the robot tilts with its velocity.
- Best score saved in localStorage.
